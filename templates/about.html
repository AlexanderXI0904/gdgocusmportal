About This Project

GDGoC USM Mass Email Application Infrastructure

Overview

The GDGoC Email Application is a custom-built solution designed to streamline personalized mass communication. Built using Python, Flask, and the Microsoft Graph API, this platform enables seamless authentication and efficient dispatch of batch emails directly from Excel payloads.

Key Features

  • Microsoft Graph Integration: Enterprise-grade security and dispatch reliability.
  • Dynamic Fields: Automatic mapping of `{{ "{{" }}Columns{{ "}}" }}` directly from uploaded `.xlsx` data streams.
  • Live Visual Editor: CodeMirror integration enabling seamless toggle between HTML and Rich Text view.
  • Background Processing: Asynchronous dispatch with real-time progress polling, ensuring the browser remains unblocked during heavy loads.

Security & Data Handling

Excel files and attachments are securely cached in a temporary directory and automatically purged upon campaign completion or application termination. Authentication relies on volatile memory states and strict MSAL standard protocols.
